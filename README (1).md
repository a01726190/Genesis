# Genesis †

### Bible Guidance & Personal Growth Chatbot

Genesis is a Christian personal-growth chatbot designed to help young people reflect on their emotions, goals, and decisions through the teachings of Jesus Christ and Bible-based guidance.

## Features
- Personalized user profile
- Daily Bible verse
- Faith Guide emotion check-in
- Bible study topics
- Personal reflection journal
- Interactive Python menu

## Technology
- Python 3
- Rule-based chatbot logic

## How to Run
1. Download or clone this repository.
2. Open the project folder in a Python environment.
3. Run:

```bash
python main.py
```

## Mission
Genesis aims to encourage faith, kindness, compassion, personal growth, and emotional well-being.

## Disclaimer
Genesis provides faith-based reflection and is not a replacement for professional counseling or trusted adult support.
